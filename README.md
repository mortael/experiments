# Math Genius Kids 🌟

An AI-powered educational math app designed for elementary school students (ages 4-12) to practice mathematics in a fun and engaging way.

## Features

### 🎯 AI-Powered Assessment
- Initial skill assessment to determine the child's current level
- Adaptive testing that adjusts to the child's age and abilities
- Analyzes performance to create a personalized learning path

### 📚 Age-Appropriate Content
- **Ages 4-6**: Counting, basic addition and subtraction (1-10)
- **Ages 7-8**: Addition, subtraction, and introduction to multiplication (up to 50)
- **Ages 9-12**: All operations including division with larger numbers (up to 100+)

### 🎮 Gamification
- Real-time score tracking
- Streak counter to motivate continuous correct answers
- Level progression system (10 levels)
- Positive reinforcement and encouragement messages
- Fun emojis and colorful interface

### 🧠 Adaptive Learning
- Difficulty automatically adjusts based on performance
- Personalized recommendations after each session
- Tracks progress and provides insights
- Multiple-choice assessment and input-based practice

### 📊 Progress Tracking
- Accuracy percentage
- Total problems solved
- Best streak achieved
- Session summaries with recommendations

## Getting Started

### Prerequisites
- Node.js (for development server)
- Modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mortael/experiments.git
cd experiments
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:8080`

### Alternative: Open Directly
You can also open `index.html` directly in your web browser without a server.

## How to Use

1. **Welcome Screen**: Enter the child's age (4-12) and name
2. **Assessment**: Complete 5 questions to determine skill level
3. **Practice Mode**: Solve math problems tailored to the assessed level
4. **Progress**: View results every 10 problems with personalized recommendations
5. **Continue**: Keep practicing to improve and level up!

## Technology Stack

- **HTML5**: Structure and semantic markup
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **JavaScript (ES6+)**: Core logic and AI-powered adaptive learning
- **No external dependencies**: Pure vanilla JavaScript for fast loading

## Educational Approach

The app uses an AI-powered adaptive learning algorithm that:

1. **Assesses** the child's current skill level through progressive testing
2. **Adapts** problem difficulty based on performance and age
3. **Encourages** with positive feedback and streak tracking
4. **Progresses** by increasing difficulty as the child improves
5. **Analyzes** performance to provide personalized recommendations
